# 全功能最小示例项目：mini-feos-debug-lab

## 1. 项目简介

`mini-feos-debug-lab` 是当前 FORGE Factory 的全功能最小示例项目。它完整演示：

```text
FORGE 五阶段项目开发
+ Claude Code for VS Code 本地模型工作流
+ Network 搜索/提取/隐私/RAG
+ FEOS Escalation Case 升级闭环
+ 高风险动作安全边界
+ 文档治理自动化
```

业务场景：一个 tiny-calculator CLI 出现 schema / test failure，本地 Agent 多次修复失败后，用 FEOS 生成升级包，人工粘贴给外部模型，导入回复，验证建议，生成执行计划，记录 outcome，沉淀 knowledge。

本文件应能独立指导用户完成示例；遇到问题再查 `docs/工厂使用手册.md`。

### 步骤 5：创建 FEOS Case

```bash
CASE_ID="$(python3 -m _infra.feos.cli create \
  --title "mini-calc output contract failure" \
  --user-goal "fix calculator CLI output contract" \
  --json | python3 -c 'import sys,json; print(json.load(sys.stdin)["id"])')"

echo "$CASE_ID"
```

预期：

```text
case_YYYY_MM_DD_001
```

---

### 步骤 6：导出 Clipboard Artifact

```bash
python3 -m _infra.feos.cli export "$CASE_ID" --gateway clipboard --provider chatgpt_web
find ".forge/feos/cases/$CASE_ID" -maxdepth 3 -type f | sort
```

预期看到：

```text
exports/clipboard.md
exports/package.json
exports/manifest.json
exports/redaction_report.json
exports/evidence_index.md
exports/audit.json
```

手工打开并复制：

```bash
cat ".forge/feos/cases/$CASE_ID/exports/clipboard.md"
```

粘贴给外部 GPT/Claude 网页。

---

### 步骤 7：导入外部回复

```bash
cat > /tmp/feos_response.md <<'EOF'
## Claims
Root cause is output contract mismatch.
## Recommendations
- Return plain integer output for calc add and add pytest coverage.
## Risks
- Changing output may break users expecting JSON.
EOF

python3 -m _infra.feos.cli import response "$CASE_ID" --response-file /tmp/feos_response.md
python3 -m _infra.feos.cli response parse "$CASE_ID"
python3 -m _infra.feos.cli verify "$CASE_ID"
python3 -m _infra.feos.cli plan "$CASE_ID"
```

预期：输出 response id、parsed id、verification id、plan id。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| Claude Code 卡住 | `scripts/model_status.sh` → `scripts/stop_local_models.sh` → `bash scripts/forge-start.sh` |
| export 被 policy block | 基础 export 默认只采 user_input；如果手工加入敏感内容，需 redaction |
| verify 后 no_plan | 检查 verification 是否 failed |
| pbcopy 不可用 | 手工复制 `exports/clipboard.md` |
| docs-check warning | warning 可读；blocker 必须修 |
