# 全功能最小示例项目：mini-gratitude（极简感恩日记 CLI）

## 1. 项目简介

`mini-gratitude` 是一个极小的命令行项目，用来记录每天 1～3 条感恩事项。

它的业务功能故意保持很小：

```text
gratitude add "今天完成了一个小目标"
gratitude list
gratitude export --format md
```

但它的演示流程覆盖 FORGE Factory 的全部核心能力：

- 需求分析
- 架构设计
- 任务拆解
- TDD 开发
- 测试
- 文档更新
- 安全审查
- 联网搜索
- Privacy Gateway 思维
- Local RAG / 记忆入库思维
- MCP 模式隔离
- 多 Agent 协作
- Bug 修复
- 功能迭代
- RETRO 与知识沉淀
- 项目交接

## 2. 项目目标

### 2.1 用户目标

用户希望用最少步骤记录积极事件，并能回看最近记录。

### 2.2 工厂教学目标

新用户通过本项目学会：

1. 如何启动工厂。
2. 如何创建新项目。
3. 如何使用五阶段流程。
4. 如何调用 Agent / Skill。
5. 如何写项目文档和 ADR。
6. 如何按 TDD 开发。
7. 如何跑测试。
8. 如何执行联网搜索与安全提取。
9. 如何进行安全审查。
10. 如何修 bug、做迭代、交接项目。
11. 如何做 RETRO 并沉淀知识。

## 3. 功能列表

### Must

- `gratitude add TEXT`：新增一条记录。
- `gratitude list --limit N`：查看最近 N 条记录。
- `gratitude export --format md|json`：导出记录。
- 本地存储，不上传隐私数据。
- 单元测试覆盖核心功能。

### Should

- 支持按日期过滤。
- 支持隐私提醒：记录内容只存本地。
- 支持导出前检查空数据。
- 支持一次 bug 修复演示。
- 支持一次功能迭代演示。

### Won't

- 不做 Web UI。
- 不做账号系统。
- 不做云同步。
- 不做复杂 AI 生成。

---

## 4. 技术方案

| 维度 | 选择 | 原因 |
|---|---|---|
| 语言 | Python | 工厂已有 Python 工具链。 |
| CLI | argparse | 避免引入额外依赖。 |
| 存储 | SQLite | 便于演示本地持久化、测试和隐私。 |
| 测试 | pytest | 项目已有 pytest 流程。 |
| 文档 | Markdown | 与工厂文档体系一致。 |
| 隐私 | local_only | 感恩日记可能包含私人信息。 |
| 联网 | Research mode 搜索资料 | 演示 Search / Extract / Privacy / RAG 能力。 |

### 4.1 架构图

```text
CLI argparse
  ↓
Command handler
  ↓
Store interface
  ↓
SQLite local DB
  ↓
Export formatter
```

### 4.2 隐私原则

- 日记内容默认视作个人数据。
- 不发送到 Tavily / Serper / 外部 API。
- 若需要联网搜索，只搜索通用资料，例如“gratitude journaling benefits”，不搜索用户真实记录。

## 9. 演示项目为何能覆盖全部能力

虽然业务只有三个命令，但每个工厂能力都被映射到流程：

- 小业务足够触发完整生命周期。
- 本地日记天然触发隐私策略。
- CLI 天然适合 TDD。
- SQLite 天然适合 ADR。
- 导出功能天然适合安全审查。
- 日期过滤天然适合功能迭代。
- 空导出 bug 天然适合 bug 修复。
- 外部资料搜索天然适合联网模块。
- 是否增加 AI 鼓励语天然适合多专家评审。
- RETRO 可沉淀极简 CLI TDD pattern。

因此它是当前工厂的“全功能最小教学项目”。
