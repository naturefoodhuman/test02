# 全功能最小示例项目：mini-gratitude-control-tower

## 1. 项目简介

`mini-gratitude-control-tower` 是一个极小但覆盖全工厂能力的教学项目。它的核心业务仍然是“感恩日记 CLI”，但增加一个 **Safety Control Tower（安全控制台）演示层**，用最小成本覆盖包括高风险能力在内的全部工厂功能。

业务功能分两层：

1. **普通功能**：记录、查看、导出感恩日记。
2. **高风险演示功能**：在受控 sandbox 中演示删除、导出、私域读取、浏览器动作、截图、MCP 拦截、Prompt Injection、Canary、Cookie 泄露防护等能力。

核心原则：

```text
高风险能力必须被演示，但只能在 sandbox / dry-run / 明确人工确认 / 无真实私域数据环境中演示。
```

## 3. 功能列表

### 3.1 普通功能

| 功能 | 命令 | 说明 |
|---|---|---|
| 新增记录 | `gratitude add TEXT` | 写入本地 SQLite。 |
| 查看记录 | `gratitude list --limit N` | 默认最近 10 条。 |
| 日期过滤 | `gratitude list --date YYYY-MM-DD` | 功能迭代演示。 |
| 导出 Markdown | `gratitude export --format md` | 普通导出。 |
| 导出 JSON | `gratitude export --format json` | Bug 修复演示。 |

### 3.2 高风险演示功能

| 高风险能力 | 演示命令 / 场景 | 安全边界 |
|---|---|---|
| 删除数据 | `gratitude delete --id 1 --dry-run` / `--confirm yes` | 默认 dry-run，必须人工确认。 |
| 批量导出 | `gratitude export --include-private --dry-run` | 默认拒绝私密字段。 |
| 私域读取 | Chrome DevTools private 读取本地 dummy profile 页面 | 禁止 cookie/localStorage/sessionStorage。 |
| 浏览器点击 | Playwright public 打开本地 demo page 并点击非提交按钮 | 写操作必须 approval。 |
| 截图 | Playwright screenshot demo | 高风险审批。 |
| Prompt Injection | 恶意 HTML fixture | InputSanitizer + security test。 |
| Cookie 泄露 | 尝试读取 `document.cookie` | MCP Guard deny。 |
| Canary Token | 文本中植入 canary | Privacy Gateway 阻断。 |
| MCP Rug Pull | schema hash 变化测试 | MCP Guard 拦截。 |
| 搜索风控 | 诊断脚本测试高风险引擎 | 只诊断，不进默认业务路径。 |

## 4. 技术方案

| 维度 | 选择 | 原因 |
|---|---|---|
| CLI | Python argparse | 最小依赖。 |
| 存储 | SQLite | 本地隐私和测试简单。 |
| 测试 | pytest | 与工厂一致。 |
| 联网 | `_infra.network.cli search` | 演示 Search / Extract / Privacy / RAG。 |
| 浏览器 | Playwright public + Chrome DevTools private | 演示模式隔离和高风险审批。 |
| 安全 | MCP Guard + Privacy Gateway | 演示拦截而非绕过。 |
| 文档 | Markdown + ADR | 工厂标准。 |

## 9. 为什么这个示例覆盖“所有功能，包括高风险功能”

它把高风险能力设计成 **可控演示**：

- 删除是真实高风险，但默认 dry-run。
- 私域读取是真实高风险，但只读 dummy profile，不读 cookie/storage。
- 浏览器截图是真实高风险，但需要 approval。
- Prompt Injection / Canary / Cookie 泄露是真实安全风险，但在 fixture 中测试。
- 搜索 CAPTCHA 是真实风控风险，但只在诊断工具中测试，不进业务默认路径。

因此它既覆盖能力，又不违反工厂安全边界。
