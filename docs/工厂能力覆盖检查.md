## 4. 安全边界覆盖

| 高风险能力 | 覆盖方式 |
|---|---|
| 外部强模型建议 | Clipboard 手工复制 / 手工导入 |
| 自动执行外部建议 | 不允许；只生成 ExecutionPlan |
| Secret / canary | Policy / Redaction 阻断 |
| 私域 / cookie | 不在最小示例真实执行；由 MCP Guard / 手册说明覆盖 |
| 全量本地 evidence 外发 | 基础 export 默认只采 user_input |

## 5. 验收标准

新用户只看 `docs/全功能最小示例项目.md` 应能完成：

```text
启动本地服务
创建 tiny project
运行 Network 搜索
创建 FEOS Case
导出 clipboard.md
导入外部回复
parse / verify / plan / outcome / distill
运行 feos-test 和 docs-check
```
