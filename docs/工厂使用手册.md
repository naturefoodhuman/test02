## 1. FORGE Factory 是什么

FORGE Factory 是本地优先的 AI 项目开发工厂。它把“模糊想法”通过阶段化工作流、Agent/Skill 协作、本地模型、联网取数、隐私网关、FEOS 升级闭环和文档治理，转化为可运行、可测试、可交接的软件项目。

核心原则：

| 原则 | 含义 |
|---|---|
| Local First | 尽量本地运行、开源优先、数据可控。 |
| Human in the Loop | 需求、架构、安全、高风险动作和知识入库必须人工确认。 |
| Evidence First | 重要结论必须有证据，不靠主观猜测。 |
| Privacy First | 外部内容和私域内容必须经过隐私网关或脱敏。 |
| Config First | 模型、路由、运行参数、FEOS、联网、安全策略都通过配置管理。 |
| Small Verifiable Steps | 每次改动都应小步、可测试、可回滚。 |
| Documentation Governance | 文档是控制面，必须跟代码同步。 |

## 2. 当前核心能力

### 2.1 Core FORGE

- 五阶段生命周期：DISCOVERY → SPEC → BUILD → HARDEN → RETRO。
- `forge` CLI：status / new / check / tasks / advance / gate / eval / compare-plans / retro。
- `_agents`：arch-advisor、security-reviewer、retro-analyst、code-explorer。
- `_factory/skills`：discovery、arch、tdd、security、data、compliance 等技能。
- `_factory/patterns/peer-review`：LangGraph HUB-SPOKE 多专家评审。
- `MemoryStore` / `KnowledgeHub` / lessons / evals。

### 2.2 Network Increment

- SearXNG 本地搜索。
- Engine Matrix + Circuit Breaker。
- Tavily / Serper API fallback。
- Crawl4AI / trafilatura / curl_cffi 提取链。
- Privacy Gateway L1-L7。
- Local RAG。
- Browser public / private pipeline。
- MCP Guard / mode isolation。
- 风控诊断工具。

### 2.3 FEOS：FORGE Escalation OS

FEOS 是当前新增的升级闭环基础设施，用于当本地 Agent 遇到失败、不确定性、上下文污染或能力边界时，把问题升级为可审计的 Escalation Case。

当前已完成 FEOS-001 ~ FEOS-056，具备 MVP 基础闭环：

```text
Case 创建
→ Evidence 采集
→ Case Graph 构建
→ Context Package 编译
→ Escalation Package 构建
→ Clipboard Artifact 导出
→ 外部回复导入
→ Response 解析
→ Verification
→ Execution Plan
→ Outcome
→ Knowledge Candidate
→ Diagnostics / Governance
```

当前 FEOS 仍是本地基础设施，不直接调用外部强模型，不自动执行外部建议。

## 6. FEOS 使用方式

### 6.1 FEOS 当前主流程

```text
create case
→ collect evidence
→ graph build
→ context compile
→ package build
→ export clipboard artifact
→ human pastes to external model
→ import response
→ parse
→ verify
→ plan
→ outcome
→ distill
```

### 6.2 创建 Case

```bash
python3 -m _infra.feos.cli create \
  --title "MCP schema validation error" \
  --user-goal "debug tool call failure" \
  --json
```

### 6.3 生成 Clipboard Artifact

```bash
python3 -m _infra.feos.cli export <case_id> --gateway clipboard --provider chatgpt_web
```

### 6.4 导入外部回复并闭环

```bash
python3 -m _infra.feos.cli import response <case_id> --response-file response.md
python3 -m _infra.feos.cli response parse <case_id>
python3 -m _infra.feos.cli verify <case_id>
python3 -m _infra.feos.cli plan <case_id>
python3 -m _infra.feos.cli outcome evaluate <case_id> --status resolved --summary "fixed"
python3 -m _infra.feos.cli distill <case_id>
```

### 6.5 FEOS 诊断

```bash
python3 scripts/diagnostics/feos_case_audit.py <case_id>
python3 scripts/diagnostics/feos_case_audit.py <case_id> --json
```

## 9. 常见问题

| 问题 | 处理 |
|---|---|
| README 自动被改 | 不正常，检查 `git diff -- README.md`，非预期则 checkout。 |
| `Developer: Reload Window` 报 zsh 错 | 这是 VS Code 命令面板命令，不是终端命令。 |
| `code .` 不存在 | 安装 VS Code Shell Command，或直接 File → Open Folder。 |
| Claude Code 卡住 | 先问 `只回复 pong`，再用 `@文件` 分步总结。 |
| Stop 后 GPU 不掉 | `scripts/stop_local_models.sh`。 |
| SearXNG CAPTCHA | 正常风险，依靠 Engine Matrix / Tavily / Serper fallback。 |
| FEOS export 被 policy block | 检查 context 是否含 canary/secret；基础 export 默认只采 user_input。 |
| 手写文档缺 LLM header 被提示 | 只是 warning；LLM 文件必须有 header。 |

## 10. 当前使用建议

1. 日常开发用 Claude Code for VS Code 面板。
2. 长文档用 `@文件`，不要一次性让本地模型自行读大量文件。
3. FEOS 处理“本地 Agent 卡住 / 需要外部强模型判断”的升级闭环。
4. 外发前必须经过 Policy / Redaction。
5. 外部建议必须经过 Verification，再生成 Execution Plan。
6. 高风险执行必须人工审批。
7. 每轮提交前运行 `make docs-check`。
